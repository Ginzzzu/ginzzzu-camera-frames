**Ginzzzu's Camera Frames** — модуль оформления видеокамер для Foundry Virtual Tabletop 14.

Модуль позволяет изменить форму и внешний вид камер участников, сохраняя штатную компоновку, управление и поведение видеопанели Foundry.

Оформление может быть общим для всего мира или персональным для каждого участника. В персональном режиме выбранный игроком стиль принадлежит именно его камере и одинаково отображается у самого игрока, Хранителя и остальных подключённых участников.

## Возможности

* оригинальная чёрно-белая маска камеры;
* круглая CSS-форма камеры;
* несколько стилей рамки:

  * сплошная;
  * двойная;
  * пунктирная;
  * сегментированная;
  * точечная;
* настройка толщины рамки;
* выбор цвета;
* различные варианты обработки рамки;
* эффект свечения;
* стеклянный блик;
* внутренняя тень;
* общие настройки оформления мира для мастера;
* персональное оформление камер игроков;
* синхронизация персонального оформления между всеми участниками;
* отдельные разрешения мастера для персональной настройки;
* разрешение или запрет отдельных категорий оформления;
* разрешение конкретных значений внутри каждой категории;
* автоматическое скрытие недоступных игроку вариантов;
* возврат к установленному мастером значению, если ранее выбранный игроком вариант становится недоступен.

## Персональное оформление игроков

Мастер может разрешить игрокам самостоятельно настраивать внешний вид своих камер.

Для каждой категории отдельно определяется, что именно разрешено изменять:

* форму;
* стиль рамки;
* толщину;
* цвет;
* обработку;
* блик;
* внутреннюю тень.

Также мастер может ограничить доступные значения внутри каждой категории.

Игрок видит только разрешённые ему настройки.

Выбранное оформление сохраняется за владельцем камеры. Например, если игрок выбрал синюю точечную рамку, именно такой его камеру будут видеть он сам, мастер и остальные подключённые участники.

## Установка

### Через Manifest URL

В Foundry VTT откройте установку модулей и вставьте следующий адрес в поле **Manifest URL**:

`https://github.com/Ginzzzu/ginzzzu-camera-frames/releases/latest/download/module.json`

### Ручная установка

[**Скачать последнюю версию модуля**](https://github.com/Ginzzzu/ginzzzu-camera-frames/releases/latest/download/ginzzzu-camera-frames.zip)

Распакуйте архив в каталог модулей Foundry VTT и перезапустите Foundry при необходимости.
