**Ginzzzu's Camera Frames** is a camera appearance module for Foundry Virtual Tabletop 14.

The module lets you customize the shape and appearance of participant camera frames while preserving Foundry's standard camera layout, controls, and behavior.

Camera appearance can be shared across the entire world or customized individually by each participant. In personal mode, a player's selected appearance belongs to that player's camera and is displayed consistently to the player, the GM, and every other connected participant.

## Features

* original black-and-white camera mask;
* circular CSS camera shape;
* multiple frame styles:

  * solid;
  * double;
  * dashed;
  * segmented;
  * dotted;
* adjustable frame thickness;
* configurable frame color;
* multiple frame finishes;
* glow effect;
* glass glare;
* inner shadow;
* shared world appearance settings controlled by the GM;
* personal camera appearance for players;
* synchronized personal appearance for all connected participants;
* GM-controlled permissions for player customization;
* category-level permissions;
* allowed values within each permitted category;
* automatic hiding of unavailable options;
* automatic fallback to the GM-defined value when a previously selected player option is no longer available.

## Personal Player Appearance

The GM can allow players to customize the appearance of their own cameras.

Permissions can be configured separately for:

* shape;
* frame style;
* thickness;
* color;
* finish;
* glare;
* inner shadow.

The GM can also control which individual values are available within each category.

Players only see the options they are permitted to use.

Personal appearance is associated with the camera owner rather than the local browser. For example, if a player selects a blue dotted frame, that player's camera will appear with the same blue dotted frame to the player, the GM, and every other connected participant.

## Installation

### Manifest URL

Open the module installation window in Foundry VTT and enter the following address into the **Manifest URL** field:

`https://github.com/Ginzzzu/ginzzzu-camera-frames/releases/latest/download/module.json`

### Manual Installation

[**Download the latest version**](https://github.com/Ginzzzu/ginzzzu-camera-frames/releases/latest/download/ginzzzu-camera-frames.zip)

Extract the archive into your Foundry VTT modules directory and restart Foundry if necessary.
